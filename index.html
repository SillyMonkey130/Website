Learn the building blocks of every web page.

HTML describes what is on a page: headings, paragraphs, links, images. Five short lessons, each with code you can copy and the result beside it.

<p class="intro">Hello, web!</p>

One element = an opening tag (which can carry attributes), the content, and a closing tag.

What HTML is

HTML stands for HyperText Markup Language. It is not a programming language: it does not calculate or make decisions. It labels content so the browser knows what each piece is.

Browsers read the labels and draw the page. CSS then controls how it looks, and JavaScript adds behavior. HTML comes first because everything else builds on it.

Every page has the same skeleton

Save this in a file called index.html and open it in your browser. Only what is inside <body> appears on the page.

index.html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>My first page</title>
  </head>
  <body>
    <h1>Hello!</h1>
  </body>
</html>
What each part does

<!DOCTYPE html> tells the browser this is modern HTML.

<head> holds information about the page, such as its title in the browser tab.

<body> holds everything visitors see.

Headings and paragraphs

Use <h1> to <h6> for headings, from most to least important, and <p> for paragraphs. Use one <h1> per page.

HTML
<h1>Bread</h1>
<h3>Ingredients</h3>
<p>You need <strong>flour</strong>,
water, and <em>patience</em>.</p>
Result

Bread

Ingredients

You need flour, water, and patience.

TagUse it for
<strong>Important text (shown bold)
<em>Emphasis (shown italic)
<br>A line break. It has no closing tag.

Links and images

Both use attributes: extra settings written inside the opening tag as name="value". A link needs href. An image needs src and alt, the text read aloud by screen readers and shown if the image fails to load.

HTML
<a href="https://developer.mozilla.org">
  Read the MDN docs
</a>

<img src="cat.jpg"
     alt="A grey cat asleep on a sofa">
Result

Read the MDN docs

The image tag would show cat.jpg here, or its alt text if the file is missing.

Lists

Use <ul> when order does not matter and <ol> when it does. Each item goes in an <li>.

HTML
<ul>
  <li>Flour</li>
  <li>Water</li>
</ul>

<ol>
  <li>Mix</li>
  <li>Rest</li>
  <li>Bake</li>
</ol>
Result
  • Flour
  • Water
  1. Mix
  2. Rest
  3. Bake

Try it yourself

Make a page about something you like. Open each question for a hint.

Which tag makes the main title?

Use <h1>, once, inside <body>.

How do I link to another page?

Wrap the words in <a href="page.html"> and close it with </a>.

Nothing changed when I edited the file.

Save the file, then refresh the browser tab. Also check that every opening tag has a closing tag.
